# Cloud & AI Solutions Architect | FY 27 Certification Roadmap

Welcome to my certification tracking portal. This site outlines my continuous learning roadmap across enterprise cloud platforms, AI application development, GitHub governance, and agentic workflows. 

---

## 🎯 Certification Pathway Overview

## 1. GitHub Administration (GH-100)
**Role Focus:** Enterprise identity, security posture, repository governance, and organization administration.  
**Estimated Prep Time:** ~32 Hours (4 Weeks)  
**Exam Format:** 60 Multiple-Choice Questions | 100 Minutes | Pearson VUE  

### Core Domains & Modules
* **User Identities & Authentication:** Enterprise Managed Users (EMUs), SAML SSO configuration, SCIM provisioning sync, and 2FA policy enforcement.
* **Access & Permissions:** Organization roles, enterprise team structures, custom repository rulesets, and branch protection policies.
* **Security Policies & Governance:** Enterprise security baselines, secret scanning, dependency policies, and global defaults.
* **API Access & Integrations:** Fine-grained Personal Access Tokens (PATs), GitHub Apps lifecycle, OAuth management, and API rate limits.
* **Workflows & Runners:** Enterprise GitHub Actions policies, runner groups, IP allow lists, and self-hosted vs. GitHub-hosted infrastructure.
* **Monitoring & Diagnostics:** Audit log streaming, usage analytics, diagnostic bundles, and enterprise connectivity troubleshooting.

---

## 2. Copilot and Agent Administration Fundamentals (AB-900)
**Role Focus:** Enterprise AI assistant governance, agent setup, data privacy, and organizational adoption.  
**Estimated Prep Time:** ~15-20 Hours (2 Weeks)  

### Core Domains & Modules
* **Copilot Deployment & Licensing:** Seat management, enterprise assignment policies, and IDE extension rollouts.
* **Privacy & Content Safety:** Enterprise data privacy boundaries, code exclusion rules, telemetry configuration, and public code matching settings.
* **Agent Administration:** Provisioning custom conversational agents, integration with enterprise telemetry, and access boundary enforcement.

---

## 3. Azure AI Application & Agent Development (AI-103 / AI-200)
**Role Focus:** Architecting custom enterprise agents, integrating Azure AI services, LLM orchestration, and RAG pipelines.  
**Estimated Prep Time:** ~30-40 Hours (4 Weeks)  

### Core Domains & Modules
* **Azure AI Services Integration:** Consuming Azure OpenAI Service, AI Search, Document Intelligence, and Speech/Vision APIs.
* **Agentic Workflows & Orchestration:** Building multi-agent systems, function calling, tool integration, and prompt engineering patterns.
* **Enterprise AI Infrastructure:** Vector indexing, Retrieval-Augmented Generation (RAG) architecture, content safety filtering, and RBAC security for AI models.

---

## 💡 Bonus Target: GitHub Actions (GH-200)
**Role Focus:** CI/CD pipeline development, automated release workflows, and enterprise action security.  
**Estimated Prep Time:** ~15-20 Hours (2 Weeks)  

### Core Domains & Modules
* **Workflow Authoring:** Triggers, matrix strategies, job dependencies, custom actions, and reusable workflows.
* **Security & Compliance:** Secrets management, OpenID Connect (OIDC) integration, runner isolation, and workflow hardening.
