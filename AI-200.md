# AI-200: Developing AI Cloud Solutions on Azure - Study Guide

Welcome to the comprehensive study guide for the **Microsoft Certified: Azure AI Cloud Developer Associate (Exam AI-200)**.

## 📌 Exam Summary & Details

* **Certification:** [Microsoft Certified: Azure AI Cloud Developer Associate](https://learn.microsoft.com/en-us/credentials/certifications/azure-ai-cloud-developer-associate/)
* **Exam Code:** AI-200
* **Passing Score:** 700 / 1000
* **Duration:** 120 minutes
* **Primary Role Focus:** Cloud Developers, Backend AI Engineers, and Azure Platform Engineers building containerized, data-heavy, event-driven backend systems for AI workloads.
* **Primary Language Focus:** Python SDKs, Azure CLI, OpenTelemetry, KQL.

## 🛠️ Essential Hands-On Topics & Code Patterns

### 1. Vector Search with Azure Cosmos DB for NoSQL
```python
# Sample: Vector Search Query in Cosmos DB NoSQL Python SDK
query = """
SELECT TOP 5 c.id, c.text, VectorDistance(c.embedding, @embedding) AS SimilarityScore
FROM c
WHERE VectorDistance(c.embedding, @embedding) > 0.75
ORDER BY VectorDistance(c.embedding, @embedding)
"""
```

### 2. pgvector Optimization on Azure PostgreSQL
* Use `HNSW` (Hierarchical Navigable Small World) index for low-latency queries vs `IVFFlat` for lower memory usage.
* Configure connection pooling using **pgBouncer** to handle scaling backend compute.

### 3. OpenTelemetry Distributed Tracing
* Use OpenTelemetry Python SDK with Application Insights Exporter (`azure-monitor-opentelemetry`) to trace RAG query execution times and vector store lookup latency.
